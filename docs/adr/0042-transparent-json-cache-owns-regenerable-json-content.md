# Transparent JSON Cache owns regenerable JSON content

Regenerable JSON-encoded parsed content belongs in the app-wide **Transparent JSON Cache**, with bodies stored under `yamibo_cache/<namespace>/<cacheKey>.json` and only thin existence, TTL, and LRU metadata in `cache_entries`. Forum home, forum board, forum thread page, and novel reader projection caches use this boundary instead of feature-specific JSON directories or the dedicated `reader_cache_entries` semantic index, while UserDefaults-backed state, WebDAV payloads, structured GRDB state, and user-retained offline content stay outside it. This keeps transparent cache layout consistent with the Android-style generic disk cache model and prevents the database from becoming a second source of truth for cache-specific parsed meaning.

# Yamibo thread identity is tid-first

YamiboReader will use Yamibo thread `tid` as the internal and persistent identity for forum, novel, manga, favorite, reading-progress, and cache records, while Yamibo thread URLs are treated as external boundary inputs or network request construction details. URL parsing may still occur at link, WebView, sharing, and HTTP boundaries, but Core domain models, store schemas, reader requests, and cache keys should carry `tid` plus explicit qualifiers such as page, author id, reverse order, post id, or content source instead of storing canonical thread URLs as identity. Thread-based `FavoriteContentTarget` values should therefore store only `threadID` and not retain a canonical URL field. This restriction applies to Yamibo thread/chapter URLs, not to image or other resource URLs whose URL is the resource identity.

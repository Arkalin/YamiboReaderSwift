# Manga chapter document moves to GRDB

Status: superseded by ADR-0046 (Transparent JSON Cache; the GRDB table model below was never shipped in its final form and `manga_chapter_documents`/`manga_chapter_document_images` no longer exist).

Manga Chapter Document cache storage will move from per-document JSON files into GRDB structured tables keyed by chapter `tid`, superseding ADR 0004's normalized-URL storage key. Manga Chapter Document loading and persistence interfaces use `tid` as their identity input rather than chapter URL, and manga chapter/domain storage should not persist chapter thread URLs as alternate identifiers. The Yamibo client layer should expose thread loading by id, following the Android shape such as `fetchThreadById(tid, authorId, reverse, page)`, with request URLs constructed below that boundary. Cache hits remain authoritative with no TTL, raw chapter HTML remains outside the app data model, and parsed chapter metadata plus ordered manga image URLs live alongside Manga Directory data in queryable tables; the URL prohibition applies to chapter thread URLs, not to manga image URLs that are chapter content and offline-cache targets.
